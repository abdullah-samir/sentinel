Network / Provisioning {{ 'ON' if prov.provisioning_enabled else 'OFF' }}

Headless Wi-Fi setup for when the Pi has no internet. Ships disabled. When enabled and the Pi is genuinely offline, it raises a temporary Wi-Fi hotspot whose captive portal lets you join a network and open the dashboard. It never touches a working connection, never runs the hotspot and a client link at the same time, and always falls back to the hotspot on failure. Configure it here while online; it activates on a future offline event. Nothing here changes the Pi until you turn it on.

Management hotspot {{ 'ON' if mgmt.mgmt_ap_enabled else 'OFF' }}

An always-on Wi-Fi network — on a dedicated USB adapter — so you can reach this dashboard from your phone at any time, even when the Pi is offline. Unlike provisioning above, it is a normal management network (no captive portal, no DNS hijack) and it stays up regardless of internet. Ships disabled. It never runs on wlan0 or the interface carrying your uplink/SSH — if the chosen adapter is missing, busy, or unsafe, the hotspot simply does not come up (there is no fallback). Nothing here changes the Pi until you turn it on.
